# Wajid & Jesmin Wedding Invitation

Component-wise React + Vite wedding invitation.

## Run

```bash
npm install
npm run dev
```

The dev script uses `--host`, so the terminal will show a Network URL you can open on a phone connected to the same Wi-Fi.

## Main customization

- `src/data.js` — names/dates, event details, venue map URL and demo photos.
- `src/components/EnvelopeIntro.jsx` + `EnvelopeIntro.css` — opening envelope.
- `src/components/ScratchSaveTheDate.jsx` — scratch card and countdown unlock.
- `src/components/EventsSection.jsx` — event layout.
- `src/styles.css` — overall site styling.
- `public/music/wedding.mp3` — optional wedding music.

The site has no RSVP/backend/database.
